# Controle de Biblioteca - Refatorado 📚

Este é um sistema de gerenciamento de biblioteca desenvolvido em programação orientada a objetos (POO), focado na aplicação de arquiteturas limpas, segurança de dados e boas práticas de codificação. 

O projeto passou por uma refatoração completa para substituir lógicas amadoras por soluções robustas e escaláveis de engenharia de software.

---

## 🚀 Principais Melhorias e Recursos

* **Herança (POO Base):** Modelagem de entidades (como usuários, funcionários e diferentes tipos de mídias/livros) utilizando o conceito de herança para reaproveitamento de código e polimorfismo.
* **Tratamento de Exceções (`try-catch`):** Blindagem do sistema contra falhas críticas, capturando erros de entrada de dados, indisponibilidade de itens ou falhas de conversão de forma amigável.
* **Uso de Enums:** Padronização de estados fixos do sistema (ex: status do empréstimo, categoria do livro, tipo de usuário), evitando o uso de strings soltas ou números mágicos e garantindo o type safety.

---

## 🛠️ Tecnologias Utilizadas

* Linguagem base de Programação Orientada a Objetos (Java / C# / C++) *(Ajuste para a sua linguagem)*
* Tratamento de erros nativo
* Estruturas de Dados eficientes
