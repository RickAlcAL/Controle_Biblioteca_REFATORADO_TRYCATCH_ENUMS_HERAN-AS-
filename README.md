# Controle_Biblioteca_REFATORADO_TRYCATCH_ENUMS_HERAN-AS-
Sistema de gerenciamento de biblioteca refatorado para aplicar boas práticas de POO. Inclui tratamento de erros robusto com blocos try-catch, organização de tipos com Enums e modelagem de dados eficiente utilizando herança. Ideal para estudo de código limpo e seguro.
